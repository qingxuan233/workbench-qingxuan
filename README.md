## 🌟 仓库定位（main 分支）

- **可通用部署模板 + 通用迭代主干**：只保留通用机制与**五个**基础场景；
- **模板与实例严格分离**：本机绝对路径、真实会话 ID、个人项目记忆一律不入库（仅由本机的 `工作台.json` 管理）；
- **机器可验证的机制闸门**：不靠个人自觉，全部靠代码体检与六步提交前红线闸（`体检.mjs` / `验收.mjs`）守护。

## 🗂️ 仓库结构（分区与归档制度）

> 根目录只放「入口 + 运行必需」；文档、历史、本机产物各有唯一落点（2026-11-07 起执行）。
> 完整规则见 [文档/文件归档制度.md](文档/文件归档制度.md)，跨板块文档索引见 [文档/README.md](文档/README.md)。

```text
<仓库>/
├─ README.md / AGENTS.md / LICENSE      # 两个人/机入口
├─ 启动工作台.bat / .vbs · 同步上游.mjs  # 运行与维护
├─ 00-核心机制/ … 13-公开情报/           # 编号知识板块（逐条见下表）
├─ 模板/ · 配图/                         # 模板与图片素材
├─ 文档/                                # 跨板块文档：索引、归档制度、总纲、新手必读、维护规矩、工具目录、更新清单
│  └─ 归档/                             # 只读：已过期/已被替代的历史文档（带 ⚠ 横幅）
├─ 12-源码照搬/                         # 应用本体（代码 + 说明/）
└─ _本机产物/                           # 本机分析/审计/探针，整目录不入库
```

| 想干的事 | 去哪 |
|---|---|
| 新增一篇文档 | `文档/`，并在 [文档/README.md](文档/README.md) 登记 |
| 文档过期了 | `git mv` 到 `文档/归档/` + 加横幅 + 登记（[SOP](文档/文件归档制度.md#7-归档流程sop五步)） |

| 检查有没有放错地方 | `node 12-源码照搬\工具\结构校验.mjs --check` |

## ⚡ 为什么需要这套工作台？

1. **5 个开箱即用的基础场景**：
   | 场景 | ID | 核心职能 | 面板组成 |
   |---|---|---|---|
   | **命令** | `command` | 工作台总览与全局调度：全景神经元记忆网络（可拖拽旋转）+ 核心调度 AI | 神经元网络拓扑、AI 会话面板 |
   | **B站** | `bilibili` | 视频理解与内容提取：内嵌真实网页浏览 + 视频提取与转录 AI | B站网页视图、AI 会话面板 |
   | **自我复盘** | `self-review` | 个人资料沉淀与周期复盘：本地文件树 + 富文本预览 + 复盘 AI | 本地文件库、Markdown/网页预览、AI 面板 |
   | **本地电脑** | `pc-cleanup` | 电脑状态看护与清理：磁盘容量监测、大文件排行、体检台账与清理 | 磁盘空间卡片、大文件排行、体检台账、AI 面板 |
   | **网页AI** | `webai` | 免费网页版大模型聚合：多模态/外部大模型聚合与独立会话 | 网页版AI助手卡片、模型状态、AI 会话面板 |

2. **现代化 2.0 界面交互架构**：
   - **整合式命令栏与侧边栏**：支持 `Ctrl/⌘ K` 全局命令面板（毫秒级切场景、搜面板、调工具、开目录），`Ctrl B` 切换侧栏，`Alt 1…9` 快速换场景。
   - **轻量模块化**：渲染器解构拆分为 `ui-shell`、`ui-command`、`ui-panels`、`ui-core`，清理 -47% 死代码，支持深浅自适应主题。
   - **工具箱抽屉**：统一矢量图标字典，收敛低频功能，彻底精简冗余按钮。

3. **魂：会话定位与三层记忆不丢**：
   - **会话绑定三字段**（`pinTarget` / `sessionTitle` / `sessionId`）：AI 明确知道「我是哪个场景、跟着哪个窗口走」，杜绝会话串台。
   - **三层记忆机制**：全局规矩（宪法层） / 场景私有记忆（`场景私有记忆.md` / `身份卡.md` / `场景画像.md`） / 项目级记忆。记忆持久落盘在文件，不随会话重置而消失，让 AI 越用越聪明。

4. **手：网页版免费 AI MCP 桥**：
   - 包含网页版 AI MCP 桥接器（DeepSeek、豆包、千问、智谱、Kimi 5 个网页版免费模型），通过本地协议转为原生工具直接调用，0 Token 成本借力外部大模型。

## 🚀 小白 5 分钟上手（人工部署）

> 想让 AI Agent 帮你自动装？请直接把 [`AGENTS.md`](AGENTS.md) 喂给它。  
> 人类手动部署，只需按以下 5 步顺序执行：

### 1. 前置准备
- 安装 **Node.js ≥ 18**（终端输入 `node -v` 确认正常输出）
- 安装 **Git**
- 安装 **DeepSeek Harness (DSH)** 桌面版（作为底层 AI 运行时引擎）

### 2. 克隆仓库并进入工作台根目录
```powershell
git clone https://github.com/qingxuan233/workbench-qingxuan.git
cd workbench-qingxuan\12-源码照搬
```

### 3. 初始化与依赖安装
```powershell
# 预演清理与引擎探测（只打印，不改文件）
node 工具\初始化.mjs --dry

# 正式初始化并自动安装 Electron 依赖（约 200MB）
node 工具\初始化.mjs --install
```
> 初始化脚本会自动探测本机 DSH 安装路径写入 `工作台.json`，清除残留会话与日志，重生身份卡和索引。

### 4. 启动工作台
```powershell
.\启动.bat
```
约 3 秒后窗口显示，顶栏出现 5 个场景标签。

### 5. 创建 5 条场景专属会话并绑定
```powershell
node 外壳\scripts\建会话.mjs --title "命令"     --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "B站"       --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "自我复盘"  --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "本地电脑"  --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "网页AI"    --cwd "$((Get-Location).Path)"
node 工具\实例化.mjs --apply
```
> 标题必须与场景名称一字不差；`--cwd` 必须传当前应用根目录。

### 6. 验收体检
```powershell
node 工具\体检.mjs
```
期望输出：`汇总：16 条断言 · 16 绿 · 0 红`。打开界面，五个场景的 AI 面板标题行均显示 `✓ 已钉绑定`。

> ⚠ **完整验收是五组命令**（体检 / 编码检查 / check-gui / ui-check / sessions --check），本页只列最常用的一条；
> 逐条期望片段与失败分支见 [`AGENTS.md`](AGENTS.md) §4，其中 `ui-check` 有一条**已记录的已知红**（详见 §5-10）。

## 🛡️ 机械化质量与提交前红线闸

本仓库践行「判据即代码」理念，防止规范退化为口头承诺：

- **自动化体检**：`node 12-源码照搬\工具\体检.mjs`
  - 16 条刚性断言覆盖端口单一性、单一真源、会话库有效性、cwd 合法性、模板防泄露、身份索引防漂移等。
- **提交前六步验收闸**：`node 12-源码照搬\工具\验收.mjs`
  - 串行执行：`编码检查` → `体检自检` → `身份索引` → `发布前检查` → `场景校验` → `代码红线`。
  - 严格拦截：源码绝对路径泄漏、真实会话 ID、eval 滥用、超长新增文件（>800行）、场景事实表漂移。
- **文件结构闸**：`node 12-源码照搬\工具\结构校验.mjs --check`
  - 根目录白名单、文档索引完整性、归档横幅、全仓文档相对链接可解析；已接入 pre-commit（见 AGENTS §10）。
- **上游变更管理**：遵循 [`仓库分工与上游变更规矩.md`](文档/仓库分工与上游变更规矩.md)，通过 `node 同步上游.mjs` 安全审查跟踪上游，防范非预期污染。
