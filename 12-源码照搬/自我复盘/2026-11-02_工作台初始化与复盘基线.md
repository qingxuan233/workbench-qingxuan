## 三、「自我复盘」场景核心机制确立

### 1. 双轨文件结构分工
- **轨道一：用户与交互交付区（`自我复盘\`）**
  - 作为外壳右上角「库」面板（`sr-files`）所观察的物理根目录。
  - 用户在库面板点击任何文件，左上角「预览」面板（`sr-doc`）即刻无缝内嵌渲染（支持 Markdown、Office 转 PDF、音视频、代码等）。
  - 所有复盘产出、周报、知识归档文件均存放于此，格式命名规范：`YYYY-MM-DD_<主题>.md`。
- **轨道二：场景机器记忆区（`引擎数据\.dsh\场景记忆\自我复盘\`）**
  - `场景私有记忆.md`：本场景唯一机器真源，维护 §〇 当前交接、核心职责、§一 边界、§二 接口、§五 坑与决策、§八 项目索引。
  - `身份卡.md` / `场景画像.md`：工具自动生成的身份与渲染器形态卡片（严禁手动修改）。
  - `项目记忆\`：长周期独立项目的上下文归档。
  - `归档\`：历史交接与冲突快照存放区。

### 2. 日常工作标准流（四步闭环）
```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  1. 读 §〇    │ ──> │  2. 资料整理  │ ──> │  3. 沉淀文档  │ ──> │  4. 记忆闭环  │
│ 接手当前状态  │     │ 查阅/分析/提炼│     │ 写入自我复盘\ │     │ 更新 §〇/§五  │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

## 四、本轮复盘发现与问题治理（已全部闭环处理）

1. **四场景记忆骨架全量补全**：
   - **问题**：`node 工具\场景记忆.mjs list` 显示除自我复盘外，`B站`、`命令`、`本地电脑` 均缺少 `项目记忆\` 与 `归档\` 目录，导致单场景 check 报错。
   - **处理**：全场景执行骨架初始化，建立缺失目录，4 个场景当前全部达到 `私有✓ 身份✓ 画像✓ 项目✓ 归档✓`，单场景 check 100% 通过。
2. **根治单一真源命名规范（A3 断言）冲突**：
   - **问题**：`工具\场景记忆.mjs` 中的 `ensureSkeleton` 存留历史过渡期逻辑（曾通过 `fs.linkSync` 建立 `<场景名>场景私有记忆.md` 硬链接），一旦执行就会触发体检 A3 断言失败（判定为非单一真源）。
   - **处理**：重构 `工具\场景记忆.mjs`，彻底移除硬链接生成逻辑，变更为强制清理旧前缀冗余文件，确保 `场景私有记忆.md` 为唯一真源，根治潜在隐患。
3. **引擎运行期缓存过滤（.gitignore 完善）**：
   - **问题**：DeepSeek 插件运行时写入 `引擎数据/.dsh/llm-deepseek/files-v3.json`，未被规则忽略导致 Git 状态产生杂质。
   - **处理**：在 `.gitignore` 中补充 `引擎数据/.dsh/llm-*/` 规则，净化工作区版本跟踪状态。
4. **本地电脑全盘体检数据就位**：
   - `本地电脑` 场景已完成全盘体检扫描（`外壳\data\pc-cleanup-scan.json`），发现 C/D 盘空间健康、可清理项 2.19 GB，已在本地电脑私有记忆中立项登记。
