# 自我复盘 · 使用指南与投递规范

> 本文件为「自我复盘」场景日常使用说明书。  
> 您在右上方「库」面板中随时点击本文件，即可在左上方「预览」大屏中查阅。

## 一、界面面板高效协作指南

工作台的「自我复盘」场景采用经典四格/上下分层布局，各面板协同分工如下：

```
┌───────────────────────────────────────┬───────────────────┐
│                                       │                   │
│          左上角：【预览】面板          │    右上角：【库】   │
│              (sr-doc)                 │    (sr-files)     │
│   75% 超大屏幕，内嵌渲染各类文档         │ 浏览 自我复盘 目录 │
│  （Markdown / PDF / 代码 / Office等）  │  （点击直接预览）  │
│                                       │                   │
├───────────────────┬───────────────────┴───────────────────┤
│                   │                                       │
│ 左下角：网页版 AI  │         右下角：【AI·自我复盘】        │
│   (sr-site-bl)    │               (sr-ai)                 │
│ DeepSeek 网页端   │     本 AI 助手会话区，听从您的指令加工     │
│  （查资料 / 检索） │    （输入指令，文档沉淀至上方库中）    │
│                   │                                       │
└───────────────────┴───────────────────────────────────────┘
```

## 二、目录结构与投递规范

本工作台在 `自我复盘\` 根目录下为您预置了清晰的分类结构：

| 目录 | 定位与建议存放内容 | 匹配预置模板 |
|---|---|---|

## 三、如何使用 AI 助手进行复盘加工

### 步骤 1：投递初始资料
将您的原始材料（支持 Markdown、TXT、代码文件、Word、Excel、PDF 等）直接拷贝或另存到 `自我复盘\` 相应的子目录中。

### 步骤 2：在右下角 AI 面板下发指令
在右下角「AI·自我复盘」对话框中，直接告诉 AI 您想加工的材料，例如：

- **场景 A：提炼周报与要点**
  > “帮我把 `周报\本周草稿.txt` 按照标准模板整理成一份正式周报，并指出存在延期风险的任务。”
- **场景 B：专项项目深度复盘**
  > “请分析 `项目复盘\v1.0上线复盘.md` 中的卡点，用 5 Why 归因法分析出系统性问题并给出改善建议。”
- **场景 C：多文档对比与总结**
  > “对比 `知识库\` 里的两份架构方案草案，输出一份包含优缺点与权衡维度的对比复盘文档。”

### 步骤 3：实时预览成果
AI 完成复盘后，会将结构化文档直接写回到 `自我复盘\` 相应目录中。您只需在右上角「库」面板中点一下新文档，左侧「预览」面板即可立即呈现完整排版的文档。

## 四、安全边界与场景纪律

1. **坚持产出可回看的文档**：所有的复盘结论均会沉淀为 Markdown 文件，不是聊天窗口的一次性回答。
2. **只写自己的地盘**：本场景只在 `自我复盘\` 交付目录及本场景私有记忆区写文件。
3. **绝不删除磁盘文件**：本场景不执行磁盘删除操作；如果需要清理无用文件，请切换至「本地电脑」场景处理。
