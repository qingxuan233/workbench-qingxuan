# 使用说明（公开模板）

## 一、它是什么

一套装在你自己电脑上的 AI 工作台：**5 个场景、5 个 AI 助手**、记忆写在本地文件里。
需要你自己的 DSH（DSH 引擎）引擎——本包**不带引擎**。

场景清单（**以 `AGENTS.md` §0 事实表为准**，标题必须一字不差）：

| 场景 ID | 标题 | 核心职能 |
|---|---|---|
| `command` | 命令 | 工作台总览与全局调度 |
| `bilibili` | B站 | 视频理解与内容提取 |
| `self-review` | 自我复盘 | 个人资料沉淀与周期复盘 |
| `pc-cleanup` | 本地电脑 | 电脑状态看护与清理 |
| `webai` | 网页AI | 网页版大模型聚合 |

> ⚠ 标题一字不差是有原因的：`实例化.mjs` 是按标题配对会话的，差一个字就配不上（见 `AGENTS.md` §2-④）。

## 二、第一次用

```powershell
cd 外壳
npm install
cd ..
.\启动.bat               # 端口 3083，不动你原有的 3080
```

> ⚠ `启动.bat` 会**自提权**（本机 explorer 常驻管理员，工作台要同级）。无人值守 / 后台起不来时，
> 先 `set WB_NO_ELEVATE=1` 再调它（见 `AGENTS.md` §5-15）。

然后给每个场景建会话（**5 条**，标题与上表一字不差；`--cwd` 必须是应用根本身）：

```powershell
node 外壳\scripts\建会话.mjs --title "命令"     --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "B站"       --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "自我复盘"  --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "本地电脑"  --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "网页AI"    --cwd "$((Get-Location).Path)"
node 工具\实例化.mjs --apply
node 外壳\scripts\sessions.mjs --check
```

## 四、记忆怎么用

- 每个场景的 AI 干完活，让它把结论写进该场景的 `场景私有记忆.md`
- 收工/换会话前：`node 工具\场景记忆.mjs 交接 --场景 <名字>`（归档旧版 + 补 §〇）
- 想确认没写坏：`node 工具\场景记忆.mjs check --场景 <名字>`
- 看所有场景状态：`node 工具\场景记忆.mjs list`

## 五、常见问题

| 现象 | 处理 |
|---|---|
| `.\启动.bat` 提示没装依赖 | 先 `cd 外壳 && npm install` |
| 启动后停在引擎页 | 点顶栏的场景标签；或等 10 秒它会自动进「命令」 |
| 面板空白 | 顶栏 ⟳ 刷新；再不行看 `外壳\server.log` |
| 端口被占 | 改 `启动.bat` 里 `DSH_PORT`（默认 3083）；`启动工作台.vbs` 只负责隐藏窗口，不含端口设置 |
| 提示「engine NOT ready」/ 派单 401 | 上一次 Electron 被强杀留下了**孤儿引擎**占着 3083，见 `AGENTS.md` §5-14 |
| 想换引擎位置 | 改 `工作台.json` 的 `engine.cliPath`（或设环境变量 `DSH_CMD`），然后重启 |
| 插件面板里 0 个插件 | 正常：公开版默认不带插件；启动动画是外壳内置效果，不是插件 |

## 七、实例场景（`scenarios/_local`）

想给**这台机器**加业务场景，但又不想污染公开模板时，用实例场景：

1. 在 `外壳\scenarios\_local\` 放一个 json（**目录已被 `.gitignore` 挡，不入库**）。文件名 = 场景 `id`
   （例如 `work-dev.json` → `"id": "work-dev"`；自检/临时场景允许 `__demo-selftest.json` 这种下划线前缀）。
2. 内容照抄 `外壳\scenarios\` 里某个模板 json 改 `id` / `name` / `panels` 即可；`type` 必须是已注册渲染器。
   定位卡（`*-context.md`）**可选**（实例场景允许省略；模板仍强制）。
3. 建会话 + 绑定（有 AI 面板时）：
   `node 外壳\scripts\建会话.mjs --title "<会话名>" --cwd "<本工作台绝对路径>"`
   → `node 工具\实例化.mjs --apply`（现在同时认模板与 `_local`，实例场景也会绑定）。
4. 校验与记录：`node 工具\场景校验.mjs --check`（模板与实例都做结构校验；**`AGENTS.md §0` 事实表只统计模板**，
   实例场景永不写入事实表），`node 工具\身份索引.mjs --stamp`（索引含实例场景），`node 工具\代码红线.mjs --check`
   （`_local` 的 panel `type` 也会被核对）。
5. 同 id 冲突：`_local` 优先（`listScenarios()` 里该项 `instance:true`，并 `console.warn`）；`getScenario()`
   与 `_派单核心.sceneRegistry()` 同样以 `_local` 为准。
6. 生效：重启工作台（或等下一次读取场景列表）。标签顺序仍以 `外壳\data\scene-tab-order.json` 为准。

## 八、外部 Agent 接入（REST / MCP / 派单）

> 定位：让 **Claude Code、Cursor、外部脚本或别的 Agent** 能调用工作台已沉淀的场景能力。
> 两个面共用同一份能力层（`外壳/core/index.mjs`，10 个能力）与同一套中间件：
> `authz → INJ-01（机密拦截）→ 限流 → 执行 → 结果修剪 → 审计`。
> ⚠ 网关**随 GUI 生死**：它跑在 `31239` 的同一个主进程里，工作台一关就没了（不是常驻服务）。

### 8.1 拿 token

| 方式 | 位置 | 说明 |
|---|---|---|
| 自动生成 | `外壳\data\gateway-token.json` | 启动即落盘（`0600`，被 `.gitignore` 挡、**不进 git**） |
| 配置固定 | `工作台.json` 的 `gateway.token` | 优先级更高，适合长期给外部工具用 |

除本机回环外的访问**必须**带 `Authorization: Bearer <token>`；跨域默认拒绝，
需要放行就在 `工作台.json` 写 `gateway.allowedOrigins = ["https://你的域"]`。

### 8.2 REST（端口 31239）

| 方法 | 路径 | 鉴权 | 用途 |
|---|---|---|---|
| GET | `/v1/health` | 匿名 | 网关 + 引擎是否就绪 |
| GET | `/v1/agents` | Bearer | 5 个场景状态 + `sessionHash`（**不泄漏真实 sessionId**） |
| GET | `/v1/tasks?limit=20&status=expired` | Bearer | 任务列表（可按状态过滤） |
| GET | `/v1/tasks/:id` | Bearer | 单任务（含信封与证据） |
| POST | `/v1/tasks/:id/claim` | Bearer | 领取任务，body `{"agent":"cursor"}` |
| POST | `/v1/tasks/:id/complete` | Bearer | 销账，body `{"evidence":"依据","exitCode":0,"artifacts":[{"path":"应用内相对路径","sha256":"可选"}]}` |
| POST | `/v1/dispatch` | Bearer | 派单：`{to,text,title?,priority?,deadlineMs?,mandate?,evidenceExpected?,idempotencyKey?}` |

```powershell
$t = (Get-Content 外壳\data\gateway-token.json -Raw | ConvertFrom-Json).token
Invoke-RestMethod http://127.0.0.1:31239/v1/agents -Headers @{ Authorization = "Bearer $t" }

$body = @{ to='命令'; title='体检派单'; priority='P1'; deadlineMs=600000;
           text='跑一次体检并把绿数回报' } | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:31239/v1/dispatch -Method Post `
  -Headers @{ Authorization="Bearer $t" } -ContentType 'application/json; charset=utf-8' `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

返回 `202 + taskId`（`awaitWake:true` 才会等唤醒结果）。**目标会话会被真正唤醒**——不是只写文件。

### 8.3 MCP（给 Claude Code / Cursor 等）

stdio（最简单，不需要工作台的 HTTP 端口）：

```json
{ "mcpServers": { "workbench": { "command": "node",
  "args": ["<应用根>/外壳/scripts/workbench-mcp.mjs"] } } }
```

Streamable HTTP（挂 `31239/mcp`，启动日志会打印 `[mcp] Streamable HTTP face 已就绪`）：

```json
{ "mcpServers": { "workbench": { "type": "http", "url": "http://127.0.0.1:31239/mcp" } } }
```

工具 12 个：`workbench__scene_status`、`workbench__dispatch_task`、`workbench__task_get`、
`workbench__task_list`、`workbench__task_cancel`、`workbench__task_claim`、`workbench__task_complete`、
`workbench__pc_inspect`、`workbench__bilibili_extract`、`workbench__review_search`、
`workbench__memory_search`、`workbench__webai_council`。

> `workbench__bilibili_extract` 读的是 **B站面板同步下来的「当前视频」**（不是联网抓取）：
> 先在 B站场景网页面板里打开一个视频，再用它查；没打开过就如实返回 `never-synced`。

### 8.4 派单 CLI（本机最省事的一条路）

```powershell
node 工具\派单.mjs --to 命令 "跑体检并把绿数回报"
node 工具\派单.mjs --to 本地电脑 --priority P1 --timeout-min 30 --expect "扫描结论" "磁盘大文件体检"
node 工具\派单.mjs --to 命令 --no-write --expect "只读结论" "只看不改：列一遍场景绑定"
node 工具\派单.mjs --list --status expired        # 看超时未回执的
node 工具\派单.mjs --claim <taskId> --agent cursor
node 工具\派单.mjs --complete <taskId> --evidence "16绿0红" --exit-code 0 --evidence-file <路径>
node 工具\派单.mjs --sweep                       # 超时未回执 ⇒ 转 expired
```

退出码：`0` 成功 ｜ `2` 用法错 ｜ `3` **入账成功但唤醒失败**（任务保留，引擎就绪后重派）｜ `1` 校验/执行失败。

信封字段（全部可选）：`--priority`（P0–P3，默认 P2）、`--timeout-min`（截止，超时由 `--sweep` 转 expired）、
`--no-write`（`mandate.allowWrite=false`，只给接手方看边界）、`--expect`（期望证据，写进台账）。
`--complete` 的 `--exit-code` / `--evidence-file` 会记成**机器证据**（文件自动算 sha256）。

### 8.5 安全边界

- **入参校验**：每个能力都有自己的 JSON Schema，`required` / 类型 / `enum` 由能力层统一校验
  （对象/数组/number 传错会直接 `400 E_VALIDATE`，**不会被悄悄转成字符串**）。
- **INJ-01**：入参里出现 `api_key:` / `sk-…` / 身份证 / 私钥 ⇒ 直接 `400 E_INJ`，**不会**发给任何模型。
- **限流** 60 次/分钟（按 `X-Workbench-Agent` 或来源 IP），超限 `429` + `retryAfterMs`。
- **ACL**：`工作台.json` 写 `gateway.acl = [{ "agent":"cursor", "allowScenes":["command"] }]`；配了就只放行这些。
- **审计**：`外壳\data\gateway-access.log` 与 `core-audit.log`（机写区，不进 git）。
- **结果修剪**：超过 6KB 自动落 `外壳\data\mcp-spool\`，只回 500 字预览 + 文件指针，防止打爆外部 Agent 上下文。

### 8.6 一条自检

```powershell
node 外壳\scripts\gateway-smoke.mjs
```

`exit 0 = VERIFIED ｜ 3 = 未验证（工作台没跑，**不算通过**）｜ 1 = FAILED`。
它已接进 `node 工具\验收.mjs` 的第 2 步：工作台没跑时会显示「跳过（未验证）」，不会假装绿。
