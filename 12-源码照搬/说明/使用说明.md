# 使用说明（公开模板）

## 一、它是什么

一套装在你自己电脑上的 AI 工作台：**5 个场景、5 个 AI 助手**、记忆写在本地文件里。
需要你自己的 DSH（DSH 引擎）引擎——本包**不带引擎**。

场景清单（**以 `AGENTS.md` §0 事实表为准**，标题必须一字不差）：

| 场景 ID | 标题 | 核心职能 |
|---|---|---|
| `command` | 命令 | 工作台总览与全局调度 |
| `bilibili` | B站 | 视频理解与内容提取 |
| `self-review` | 自我复盘 | 个人资料沉淀与周期复盘 |
| `pc-cleanup` | 本地电脑 | 电脑状态看护与清理 |
| `webai` | 网页AI | 网页版大模型聚合 |

> ⚠ 标题一字不差是有原因的：`实例化.mjs` 是按标题配对会话的，差一个字就配不上（见 `AGENTS.md` §2-④）。

## 二、第一次用

```powershell
cd 外壳
npm install
cd ..
双击 启动.vbs        # 端口 3083，不动你原有的 3080
```

然后给每个场景建会话（**5 条**，标题与上表一字不差；`--cwd` 必须是应用根本身）：

```powershell
node 外壳\scripts\建会话.mjs --title "命令"     --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "B站"       --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "自我复盘"  --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "本地电脑"  --cwd "$((Get-Location).Path)"
node 外壳\scripts\建会话.mjs --title "网页AI"    --cwd "$((Get-Location).Path)"
node 工具\实例化.mjs --apply
node 外壳\scripts\sessions.mjs --check
```

## 三、日常

| 想干什么 | 怎么做 |
|---|---|
| 切场景 / 找面板 / 开工具 | `Ctrl K` 打开命令面板，输入名字回车 |
| 收起 / 展开左栏 | `Ctrl B`（顶栏 `⋯` 里也有） |
| 聚焦当前面板 | 面板标题右侧 `⛶`，或 `Ctrl Shift F`；`Esc` 退出 |
| 切场景（键盘） | `Alt 1…9`（按左栏顺序） |
| 回旧界面 | 顶栏 `⋯ → 切换 2.0 / 经典界面`，或地址加 `?ui=classic` |
| 加场景 | 复制 `外壳\scenarios\` 里一个 json，改 `id`/`name`/`panels`；同步 `_场景身份索引.md`；跑 `建会话.mjs`；顶栏 ⟳ |
| 改面板 | 改 `外壳\scenarios\<场景>.json`，顶栏 ⟳ 热更新 |
| 改界面后自检 | `node 外壳\scripts\ui-check.mjs` |
| 渲染器死代码审计 | `node 外壳\scripts\renderer-audit.mjs`（只读；类型覆盖 / 死候选 / 孤儿函数 / 体量） |
| 主进程场景模块自测 | `node 外壳\scripts\scenes-store.test.mjs`（4 组，不碰实例数据） |
| 主进程清点模块自测 | `node 外壳\scripts\inventory.test.mjs`（6 组，测试密钥脱敏与配置解析） |
| 全量标准化体检 | `node 工具\全量标准化体检.mjs`（10 类 41 项汇总，覆盖写 `_体检-latest.json` 与报告） |
| 不连引擎看界面 | `cd 外壳 && .\node_modules\.bin\electron scripts\ui-preview.cjs` |
| 备份界面 | `node 外壳\scripts\backup-gui.mjs` |
| 还原界面 | `node 外壳\scripts\restore-gui.mjs` |
| 打包带走 | `node 工具\封装.mjs --out <盘根>:\发布` |
| 出包前自检 | `node 工具\发布前检查.mjs` |

## 四、记忆怎么用

- 每个场景的 AI 干完活，让它把结论写进该场景的 `场景私有记忆.md`
- 收工/换会话前：`node 工具\场景记忆.mjs 交接 --场景 <名字>`（归档旧版 + 补 §〇）
- 想确认没写坏：`node 工具\场景记忆.mjs check --场景 <名字>`
- 看所有场景状态：`node 工具\场景记忆.mjs list`

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 双击 启动.vbs 提示没装依赖 | 先 `cd 外壳 && npm install` |
| 启动后停在引擎页 | 点顶栏的场景标签；或等 10 秒它会自动进「命令」 |
| 面板空白 | 顶栏 ⟳ 刷新；再不行看 `外壳\server.log` |
| 端口被占 | 改 `启动.bat` 里 `DSH_PORT`（默认 3083；`启动.vbs` 只负责隐藏窗口，不含端口设置） |
| 想换引擎位置 | 改 `工作台.json` 的 `engine.cliPath`（或设环境变量 `DSH_CMD`），然后重启 |
| 插件面板里 0 个插件 | 正常：公开版默认不带插件；启动动画是外壳内置效果，不是插件 |
