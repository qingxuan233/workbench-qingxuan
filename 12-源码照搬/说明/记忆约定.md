# 记忆约定（1 页）

> 这套工作台的记忆是**文件**，不是聊天记录。每个场景一个文件夹，AI 开场先读它。

## 一、放在哪

```
引擎数据\.dsh\场景记忆\
  命令\场景私有记忆.md       ← 这个场景的记忆（唯一真源）
  命令\_文件索引.md          ← 这个场景有哪些文件
  命令\归档\               ← 交接时把旧版挪进来（只进不改）
  _共享记忆\               ← 多个场景都要用的东西
```

## 二、一份私有记忆的格式

- `## §〇 当前交接`：四小节（上次交接 / 当前项目 / 私有记忆变更 / 下一步·卡点），**≤4 KB**
- `## 核心职责`：≥3 条（负责什么 / 不碰什么 / 一句话）
- `## §一 ~ §五`：职责边界 / 现状接口 / 坑与决策（**只追加**）

## 三、四条铁律

1. **§〇 ≤4 KB**：只写"下一轮接手要知道的"，细节进 §五 或归档
2. **交接才归档**：`node 工具\场景记忆.mjs 交接 --场景 <名字>` 会把旧版挪进 `归档\`
3. **只追加**：§五 决策与坑只往下写，不改历史
4. **check 不过别换会话**：`node 工具\场景记忆.mjs check --场景 <名字>`

## 四、常用命令

```powershell
node 工具\场景记忆.mjs list                 # 看每个场景缺什么
node 工具\场景记忆.mjs init --场景 命令      # 生成身份卡/画像（首次）
node 工具\场景记忆.mjs stamp --场景 命令     # 重新生成身份卡/画像
node 工具\场景记忆.mjs 交接 --场景 命令      # 归档旧版 + 补 §〇
node 工具\场景记忆.mjs check --场景 命令     # 自检
```

## 五、跨场景

`node 工具\发消息.mjs --to B站 "帮我看下这个"` —— 纯文件，不发网络请求。对方下一轮读自己的 §〇-通知 就能看到。

## 六、人写区 / 机写区（2026-11-08 起 · ADR-10）

**规则一句话：一份文件只允许一类写者。**

| 区 | 谁写 | 进 git 吗 | 典型文件 |
|---|---|---|---|
| **人写区** | 人或 AI 的**显式编辑**（含 `场景记忆.mjs 交接` 这类人发起命令） | ✅ 进（可 diff、可评审、可回滚、可审计） | `场景私有记忆.md` · `身份卡.md` · `场景画像.md` · `项目记忆\*.md` · `_共享记忆\areas\*.md` · `_待办.md` · `冲突.md` |
| **机写区** | **只有运行时**（派单、发消息、待确认、刷新面板、拖标签排序） | ❌ 不进（`.gitignore` 已挡，属本机产物） | `_共享记忆\_跨场景通知.md` · `_共享记忆\_任务台账.jsonl` · `_共享记忆\待确认.jsonl` · `外壳\data\*` 运行产物（`scene-tab-order.json`、`gateway-token.json`、`reload-panels.cmd` 等） |

三条判据：

1. **运行时代码只写机写区**：`派单.mjs` / `_派单核心.mjs`（网关与 MCP 都走它）**只** append `_跨场景通知.md`，不碰任何 `场景私有记忆.md`。
2. **改人写区必须是人发起的显式命令**：下面这几个"显式命令"允许写人写区，因为它们是**人/场景 AI 主动敲的**，且改动会进 `git diff` 供 review——
   `场景记忆.mjs init/stamp/交接`（重写 §〇 与身份卡）、`发消息.mjs --to`（追加 `## 〇-通知`）、`实例化 --apply`（只改 `工作台.json`，属实例真值）。
   **除此之外的自动化路径一律不许 append 人写区**（这是 2026-11-08 ADR-10 的硬边界）。
3. **`git status` 里出现机写区文件 = ignore 规则漏了**：先补 `12-源码照搬\.gitignore` 的机写区段，再把该文件 `git rm --cached`（磁盘文件保留），不要直接 `git add`。
